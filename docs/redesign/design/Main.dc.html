CH·01 — About

I build the boring parts well, so the ambitious parts can ship.

I started in web engineering and moved quickly toward the parts of the stack where correctness compounds: data models, service boundaries, queues, caches, and the observability that tells you the truth at 3am.

“Scalable systems” in my work means capacity that is a config change rather than a rewrite: stateless services, idempotent workers, explicit backpressure.

“AI-first” means the LLM is a component with a contract — retrieval you can inspect, evals in CI, structured outputs, and graceful degradation when the model is wrong.
